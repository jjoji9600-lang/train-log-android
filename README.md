# 练一练 · TrainLog

专为极简徒手锻炼和初级艾扬格瑜伽自练设计的 Android 离线记录工具。无账号、无网络权限、训练数据只存储在手机中。

## 功能
- 力量训练：引体向上、俯卧撑、徒手深蹲，每组次数、关节弹响/疼痛与备注
- 瑜伽：6 个初级站姿与放松体式，附参考时间与动作要点
- 瑜伽日志：体式完成勾选、实际练习分钟数、身体不适和动作观察
- 历史记录、力量最佳单组次数折线图、近 28 天瑜伽练习次数
- 力量与瑜伽分别导出 UTF-8 CSV

## 建议的 12 周练习安排
每周安排 2～3 次约 15～20 分钟的基础瑜伽练习，不追求姿势难度和极限拉伸：
1. 山式：60 秒
2. 三角伸展式：左右各 2 次，每次 20～30 秒（可扶瑜伽砖）
3. 战士二式：左右各 2 次，每次 20～30 秒
4. 战士一式：左右各 1 次，每次 20～30 秒
5. 靠墙半下犬式：2 次，每次 30 秒
6. 摊尸式：3～5 分钟

记录目标：最近 28 天至少 8 次练习；动作稳定、呼吸自然、没有持续疼痛。动作示范和现场指导优先于本 App 的文字说明。

**安全说明：头倒立、肩倒立不列入自学清单。** 建议在有资质教师观察下复核颈肩承重、动作进入和退出。若出现疼痛、麻木、眩晕、关节肿胀等不适，停止相应动作并视情况咨询医疗专业人员。

## APK 构建与安装
推送 main 分支将触发 GitHub Actions 的 `Build APK`，从该工作流页面的 Artifacts 下载 `TrainLog-debug-apk`，解压后安装 `app-debug.apk`。

这是用于个人测试的 debug APK。不同云端 Runner 可能产生不同的 debug 签名：**安装下一次更新可能要求先卸载旧版本，卸载会清除本地数据**。升级前请先导出 CSV。当前版本仅支持 CSV 导出，不支持从 CSV 导回。

数据库升级到 v2 的代码保留原有力量记录；但前提是新旧 APK 使用相同签名且能原位更新。

## 技术
Android 原生 Java + SQLite，Gradle 8.9，Android Gradle Plugin 8.7.3，minSdk 24，compileSdk 35。
