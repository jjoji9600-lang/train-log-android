# 练一练 · TrainLog

极简 Android 离线训练记录 App。支持引体向上、俯卧撑、徒手深蹲和艾扬格瑜伽体式库。无账号、无网络权限；训练记录、用户导入的瑜伽参考照片留在手机上。

## 1.2.0：自由选择瑜伽体式
- 内置 44 个常见体式，按 **站姿 / 坐姿 / 前屈 / 后弯 / 扭转 / 倒置 / 放松** 分类。
- 支持按名称搜索、点击体式查看动作提示。
- 每个体式都可通过 Android 系统文件选择器 **从手机导入或替换参考照片**；App 会保留其本地读取权限，仓库内不包含《瑜伽之光》的受版权保护照片。
- 每次练完勾选体式，统一保存。练习时长、身体不适、备注均可选填。
- 旧版 1.1.0 六体式日志自动兼容读取，依然能查看历史与导出；无需重新录入。
- 体式库不等于固定跟练课程。倒置体式仅供查阅；头倒立、肩倒立需要现场指导下评估颈部承重安全。

## 力量训练
引体向上、俯卧撑、徒手深蹲，支持每组三组次数、关节弹响、疼痛情况及备注。训练历史与最佳单组次数折线图保留。

## 数据与备份
所有记录保存到手机 SQLite。可分别导出力量与瑜伽 CSV 备份。**当前不支持 CSV 导入**。参考图来自你选定的手机文件，替换或删除原始文件可能导致图片需要重新选择。

## 构建 APK
提交到 `main` 自动触发 GitHub Actions「Build APK」。从工作流详情底部 Artifacts 里下载 `TrainLog-debug-apk` ZIP，解压安装 `app-debug.apk`。

⚠️ 云端 Debug APK 在不同 Runner 上可能签名不同，不能保证覆盖安装旧版。**卸载 App 会删除手机上的历史数据与导入图片的引用；升级前先导出 CSV**。当签名不匹配时不要直接卸载有记录的旧版，先规划数据迁移。

## 技术
Android 原生 Java + SQLite，Gradle 8.9，Android Gradle Plugin 8.7.3，minSdk 24，compileSdk 35。没有服务器或第三方库。
