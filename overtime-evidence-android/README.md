# 加班留证 · Overtime Evidence (Android MVP)

用于日常保存加班相关材料并按**单次加班事件**整理、导出。**本应用只是证据整理辅助工具，不会自动认定加班、计算应付加班费，也不能保证仲裁采纳。**

## 已实现

- 一键开始、结束加班记录（使用手机系统时间；未自动扣除休息时间）。
- 从相册/文件管理器导入图片、PDF、文本或其他文件；在微信、钉钉等 App 里使用 Android **分享**功能发送截图到「加班留证」。
- 调用系统相机拍照并归档。无活跃加班事件时，导入会创建「待整理」记录。
- 将材料标记为「公司安排 / 工作过程 / 工作结果 / 考勤记录 / 工资依据 / 其他」，填写备注。
- 附件导入时保留输入流的原始字节，计算 SHA-256，使用 Android Keystore 提供的 AES-256-GCM 密钥加密后存入应用私有目录。
- 根据材料类别提示常见缺口，不评判胜诉概率。
- 按事件导出 ZIP：`report.pdf`（目录）、`manifest.json`（结构化清单）、`originals/`（解密后的原始文件字节）、`SHA256SUMS.txt`（哈希校验）、`README.txt`。
- 默认无网络权限；无需注册和账号。使用 Android 文档选择器和分享权限，不申请访问整个手机存储的权限。

## 隐私 / 证据边界

- **附件内容加密**；事件标题、备注、附件文件名、时间和哈希存储在应用私有目录的 `manifest.json` 中，**MVP 暂未对这些元数据加密**。设备被入侵或 root 后无法保证这些数据不被访问。
- 加密密钥位于 Android Keystore，**不能通过拷贝 App 数据目录跨设备恢复**。不要只依赖本地存储；定期导出到可靠位置。卸载 App 可能造成不可恢复的数据丢失。
- 导出 ZIP **不加密**，包含原始文件。保存、传输或提交前检查无关的个人信息、客户隐私和商业秘密；只收集依法可留存的材料。
- 设备时钟、原始文件的元数据以及截图内容**不构成第三方可信时间戳**；SHA-256 只能校验保存之后有无改变，不能证明截图拍摄之初真实。
- 分类/备注是**用户的陈述**，不代表仲裁机关或法院已经确认。
- 导入的截图可能不包含全部上下文，尽量保留完整原始聊天、任务、考勤系统记录和其他客观材料。

## 如何构建

需要 JDK 17、Android SDK Platform 36、Gradle 8.13 和联网下载 Gradle/AndroidX 依赖，或者通过 Android Studio 打开根目录并配置本地 Gradle 8.13。此快照未包含 Gradle Wrapper JAR。

```bash
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
```

调试包位置：`app/build/outputs/apk/debug/app-debug.apk`。

GitHub Actions 工作流 `.github/workflows/android.yml` 也会执行单元测试并构建调试 APK，上传 Actions artifact。**构建前请勿把源码状态视为经过设备验证的成品。**

## 使用步骤

1. 点击「开始加班」填写任务，随手导入领导安排截图、考勤、工单及工作结果。
2. 点击「结束加班」，备注休息时间或其他需要说明的内容。
3. 进入该加班记录，为每件材料补充分类及用途。
4. 点击「导出 ZIP」，确认清单后将 ZIP 妥善备份。提交材料前建议由劳动法律专业人士审查。

## 技术

Kotlin + Jetpack Compose；应用私有文件存储 + 原子写入 JSON 元数据；AES-GCM（Android Keystore）；Android `PdfDocument`、`ZipOutputStream`。设计为离线单机 MVP，不含云端、账号、广告、埋点。
